# Socialite

App para estudiantes universitarios: grupos de estudio y hacer contactos, todo dentro del entorno del campus.

## Que hace (v1 / MVP)
Verificacion con correo institucional. Crear o unirse a grupos de estudio por curso y horario. Matching basico por curso, horario e intereses. Grupo formado con chat y lugar sugerido dentro del campus.

## Que NO hace todavia
Sin chat en tiempo real propio, por ahora se coordina fuera de la app. Sin app nativa: arranca como app web. Sin eventos con direccion externa, todo ocurre dentro del campus.

## Stack
Backend con Flask y Flask-SQLAlchemy. Base de datos SQLite en desarrollo.

## Como correrlo en local

git clone https://github.com/1nstall-er/socialite.git
cd socialite
pip install -r requirements.txt
python app.py
